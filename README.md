# Pixel Gridiron Network

A 24/7 pixel-art college football TV channel that runs in the browser.

**Watch:** https://asherhawk-school.github.io/pixel-gridiron-network/

- A made-up league of 24 schools is simulated play by play from the clock, so everyone watching sees the same snap at the same moment. No server.
- A league week airs every six hours, one game per half hour: pregame studio show, two 12-minute halves, halftime, replays and fake commercials.
- Each season runs about 3.5 days: 12 weeks, nine bowls, a four-team playoff, a national championship and a classics week.
- Keys: **G** program guide, **M** sound, **F** fullscreen.

One self-contained `index.html`, no build step. To jump to a moment for testing, add `?t=2026-11-14T17:58:30Z` to the URL.

Every school, player and sponsor is fictional.
